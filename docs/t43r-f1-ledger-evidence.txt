=======================================================================

Audit target this repairs: T43-AV's measurement on origin/main 8ad4141a, post
`rfu9jjxubtrdxm5kb4sipmfjkw`: in `.bridge` mode the app showed no banner, no read-out record, **and**
the persisted `mm.mentions.state.34D540A3-…` gained that post id and its create_at — so the T14 poll
would refuse it for ever.

The repair: `NativeNotificationFeed.handle` checks the input gate **before every ledger write**, and the
ring is written only by a delivery attempt (`.deliver`) or a drop the reader's own configuration decided
(`MentionDropReason.recordsAsHandled`).
